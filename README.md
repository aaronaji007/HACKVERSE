# Run Locally

Prerequisite: Node.js 24.19.0 (see `.nvmrc`).

1. Install dependencies with `npm install`.
2. Create `.env.local` and set the server-only `OPENAI_API_KEY`.
3. Start the app with `npm run dev`; requests are handled by the local `/api/extract` proxy.
4. Open the local Vite URL, usually `http://localhost:3000`.
